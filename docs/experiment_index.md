# BBBC045 实验索引

最后核对：2026-10-30。此页用于快速定位当前项目状态，**不是完整实验报告**；精确数值以本地 `runs/` 内对应的 `summary.json`、`test_metrics.json` 和运行配置为准。`runs/` 不提交 Git，换电脑后需另行取得这些产物。

## 任务与划分

- 100,105 个 55×55 单通道明场图块，四类：淋巴细胞（原 B＋T）、嗜酸性粒细胞、单核细胞、中性粒细胞。模型基线为适配小图的 ImageNet 初始化 ResNet-18。
- 交叉验证使用原 train＋val 的 84,815 张图块，按受试者分三折；`CRF101_2014` 和 `CRF101_2015` 保守地视为同一划分组，**不代表已经证实是同一人**。
- 原保留测试集为 CRF049、CRF066，共 15,290 张；它们不进入上述交叉验证，是为保持历史划分，不是因已确认错标而剔除。该测试集已被多次查看和分析，后续成绩不可再称为全新独立测试。

## 功能与诊断入口

- **RMD 特征待定：** 训练侧拟合 512 维参考，完整验证 16,221 张上按 1% 已知误拒目标校准；当前工作点约 `0.00149634`，162 张进入复核。这不是未知细胞检出率；置信度阈值方案已停用。
- **质量检查：** 当前质量下限约 `8.060`，完整验证中拦截 44 张；显式传入质量参考才启用低清晰度不合格标记。人工初筛、退化试验及校准详情集中见[质量与 RMD 探索](bbbc045_diagnostics.md#质量与rmd复核探索)，不能把经验拦截比例当作误判废率。
- **亮度与标签核查：** CRF022 的强度偏移、CRF049 旧权重敏感性、CRF101 验证尖峰，以及 TIFF／CIF 的 376/376 来源核对，统一见[数据异常与诊断记录](bbbc045_diagnostics.md)。保留官方标签，不凭模型错分删样本或改标签。
- **患者 PDF 与展示样例：** 从已有复核结果导出每位患者一份总表与真实图册，不重新推理；支持待复核、质量不合格及逐图明细。可直接[查看 2 页演示 PDF](assets/patient_report_demo.pdf)，输入格式见[患者 PDF 导出](reproduction.md#患者-pdf-导出)。演示按配额选取 60 张公开 BBBC045 图块，使用 DEMO 编号，不是真实患者或病理诊断验证，也不用于计算总体性能。
- **安装与命令：** 快速展示和数据准备见[README](../README.md)；完整参数见[运行与诊断指南](reproduction.md)。
