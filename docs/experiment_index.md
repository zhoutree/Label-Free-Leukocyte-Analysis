# BBBC045 实验索引

最后核对：2026-10-27。此页用于新对话快速定位当前项目状态，**不是完整实验报告**；精确数值以本地 `runs/` 内对应的 `summary.json`、`test_metrics.json` 和运行配置为准。`runs/` 不提交 Git，换电脑后需另行取得这些产物。

## 任务与划分

- 100,105 个 55×55 单通道明场图块，四类：淋巴细胞（原 B＋T）、嗜酸性粒细胞、单核细胞、中性粒细胞。模型基线为适配小图的 ImageNet 初始化 ResNet-18。
- 交叉验证使用原 train＋val 的 84,815 张图块，按受试者分三折；`CRF101_2014` 和 `CRF101_2015` 保守地视为同一划分组，**不代表已经证实是同一人**。
- 原保留测试集为 CRF049、CRF066，共 15,290 张；它们不进入上述交叉验证，是为保持历史划分，不是因已确认错标而剔除。该测试集已被多次查看和分析，后续成绩不可再称为全新独立测试。

## 已知问题与证据入口

- **保守质量工作点（2026-10-28）：** 直接复用 `reports/cell_review_reference/validation_scores.csv`，不重新推理。各类低清晰度拦截预算 1%，取最小类内工作点，统一下限为 `8.059967284809368`。完整验证 16,221 张中有 44 张低于下限（0.2713%），均为淋巴细胞（44/4,475，0.9832%），其余三类为零；这也提示天然纹理差异仍会影响代理评分。质量参考保存在本地 `reports/cell_quality_threshold_20261028/quality_threshold.json`；通过 `predict --quality-reference` 显式启用不合格标记，保留原图和候选类别。没有正式可用／不可用真值，因此该比例不是误判废率或失焦检出率，不通过排除图片改写原分类成绩。以下 2026-10-27 的“未启用”描述为当时的历史状态。

- **成对质量退化诊断（2026-10-27）：** 8、23、39 号仍有明显局部边缘，现有模型均分对，RMD 均未拒绝；不能据此证明质量合格，也不能凭外观差异认定无法分类。冻结原最佳权重，对此前 40 张探索样本（每类 10 张）做 11 种条件、共 440 个图块前向：原图与高斯 sigma=0.5 为 40/40 正确；sigma=1、1.5、2.5 分别为 39/40、34/40、27/40，macro-F1 分别为 0.9749、0.8423、0.5917。水平 5 像素均值模糊为 36/40；灰度偏移 ±0.0001 与噪声 sigma=0.00002 均为 40/40；对比度缩为 0.7 为 39/40。梯度及拉普拉斯总体随模糊下降，归一化梯度在轻微模糊时略升，并非严格单调。报告位于本地 `reports/cell_quality_missed_audit_20261027/` 和 `reports/cell_quality_paired_stress_20261027/`。只运行小样本诊断，不更新权重；结果不代表总体性能、真实失焦检出率或正式判废阈值，暂不启用自动判废。

- **特征参考与质量初筛（2026-10-27）：** 常规最佳权重的 512 维特征已完成训练侧拟合和完整验证侧工作点校准：训练 68,594 张、验证 16,221 张，RMD 阈值 `0.0014963410794734955`，162 张进入复核；原有 74 个验证错分中包含 41 个，另有 121 张正确预测进入复核。报告为本地 `reports/cell_review_reference/`，这不是未知类别检出验证。40 张左右对照图由用户进行非专家视觉初筛：8 张不可用、3 张存疑、其余 29 张“大概可用”（保留初步判断属性）。23 号备注为用户指出疑似拍摄抖动，成因未核实；不可用样本中 7 张为淋巴、1 张为中性粒，不能推广为四类统一质量标准。同批探索中，若不筛掉 29 张初步可用样本，归一化梯度仅筛出 3/8 张不可用，原始梯度及拉普拉斯各为 5/8，后两者均漏掉 8、23、39 号；3 张存疑未参与二分类计算。人工记录与分数对照保存在 `reports/cell_quality_label_analysis_20261027/`，原始空白表和图片不修改。阈值未自动启用，结果不作为独立验证或临床判废依据。

- **历史置信度试算（已停用）：** 第一折曾以分类分数 0.8 试算，27,062 张中送复核 220 张、拦住 71/148 个错分。历史报告保留在本地 `reports/confidence_review_fold01_20261027/`；按用户要求，当前已移除该算法、命令入口和专用测试，仅保留 RMD 特征待定及独立质量预警。分类分数仍作展示信息保存，不参与拒识。
