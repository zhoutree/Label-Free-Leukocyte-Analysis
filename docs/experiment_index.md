# BBBC045 实验索引

最后核对：2026-10-15。此页用于新对话快速定位当前项目状态，**不是完整实验报告**；精确数值以本地 `runs/` 内对应的 `summary.json`、`test_metrics.json` 和运行配置为准。`runs/` 不提交 Git，换电脑后需另行取得这些产物。

## 任务与划分

- 100,105 个 55×55 单通道明场图块，四类：淋巴细胞（原 B＋T）、嗜酸性粒细胞、单核细胞、中性粒细胞。模型基线为适配小图的 ImageNet 初始化 ResNet-18。
- 交叉验证使用原 train＋val 的 84,815 张图块，按受试者分三折；`CRF101_2014` 和 `CRF101_2015` 保守地视为同一划分组，**不代表已经证实是同一人**。
- 原保留测试集为 CRF049、CRF066，共 15,290 张；它们不进入上述交叉验证，是为保持历史划分，不是因已确认错标而剔除。该测试集已被多次查看和分析，后续成绩不可再称为全新独立测试。

## 已知问题与证据入口

- **亮度与批次：** CRF022/T/batch2 有明显强度偏移；训练时亮度／对比度扰动改善了该批失效。CRF049 的旧权重错分也对亮度调整敏感，但它不等同于 CRF022 的单批大幅变暗。CRF101 的中途尖峰触发机制尚未确定。详见[亮度实验汇总](bbbc045_brightness_findings.md)。
- **标签与图块：** CRF049 单核图块的原始 TIFF 到打包图块逐像素对应已核对；高置信度错分不能证明官方标签错误。详见[测试与标签异常记录](bbbc045_test_audit.md)。不要据此自动改标签或屏蔽整组。
- **代码与使用：** 环境安装与快速运行见[README](../README.md)；完整训练、交叉验证、评估和诊断命令见[运行与诊断指南](reproduction.md)；源码与测试的逐文件审查见[代码审查清单](code_audit_checklist.md)。

新实验成为主要参考时，只更新此页的运行快照与结论入口；详细分析仍放专项文档，逐轮曲线、预测 CSV 和权重留在忽略的运行目录。
